Getting Started

Welcome to ChronosTrade developer hub. Our platform provides ultra-low-latency market data, execution, and AI-powered analytics via REST, WebSocket, and native scripting APIs.

Authentication: All API requests require an API key. Generate one from the ChronosTrade desktop app under Settings → API Management. 
# Example: authenticate using API key
curl -X GET "https://api.chronostrade.io/v1/account" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json"

Base URL https://api.chronostrade.io/v1 | Rate limits 1000 req/sec for Pro, 200 req/sec for Explorer.

WebSocket Streams

Real-time market data with sub-millisecond updates. Connect to wss://ws.chronostrade.io/v1/stream

// Subscribe to order book & trades
const ws = new WebSocket('wss://ws.chronostrade.io/v1/stream?api_key=YOUR_KEY');
ws.onopen = () => {
  ws.send(JSON.stringify({
    action: 'subscribe',
    channels: ['trade.BTC/USDT', 'depth.BTC/USDT']
  }));
};
ws.onmessage = (event) => console.log(JSON.parse(event.data));
Channels available: trade, depth, ticker, kline_1m, kline_5m, l2_orderbook.

Scripting Sandbox

Build custom indicators, strategies, and trade automations using Python or JavaScript inside ChronosTrade desktop environment.

Python Example — Custom Indicator

# Custom RSI divergence detector
from chronos import Context, MarketData

def compute_divergence(data: MarketData):
    prices = data.close[-20:]
    rsi = calculate_rsi(prices)
    if rsi[-1] < 30 and prices[-1] > prices[-5]:
        Context.alert("Bullish divergence detected", symbol=data.symbol)
        return {"signal": "buy", "confidence": 0.82}
    return None

JavaScript Strategy — Auto Grid

// Simple grid trading bot
const { placeOrder, getBalance } = require('chronos-api');

async function gridStrategy() {
  const price = await getPrice('BTC/USDT');
  const lower = 42000, upper = 44000;
  if (price < lower && getBalance('USDT') > 1000) {
    await placeOrder('BTC/USDT', 'buy', 0.01, 'market');
    log('Grid buy executed');
  }
}

Code Examples

Fetch OHLCV data & compute VWAP

import requests
import pandas as pd

response = requests.get(
    "https://api.chronostrade.io/v1/market/klines",
    headers={"X-API-Key": "your_key"},
    params={"symbol": "BTC/USDT", "interval": "5m", "limit": 100}
)
data = response.json()
df = pd.DataFrame(data)
vwap = (df['volume'] * df['close']).sum() / df['volume'].sum()
print(f"VWAP: {vwap}")

Place OCO (One-Cancels-Other) order

const ocoOrder = {

Developer FAQ

Q: How do I get access to historical tick data?
A: Use /v1/market/historical-ticks endpoint. Requires Pro plan or higher.
Q: Does ChronosTrade support FIX protocol?
A: Yes, institutional plans include FIX 4.4 connectivity. Contact sales for credentials.
Q: Can I run my scripts 24/7 on cloud?
A: Scripts run locally on your machine. For cloud deployment, use our REST API and scheduled tasks.
